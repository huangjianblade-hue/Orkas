# Orkas

**ทีมงาน AI ที่เปิดแหล่งที่ใช้อยู่บนโต๊ะทํางานของคุณ มันเปลี่ยนเป้าหมายของคุณเป็นงานสําเร็จรูป และทําให้มันเคลื่อนไหว**

Orkas เป็นแอปเดสก์ท็อปโอเพนซอร์ส (MIT) แบบหลายเอเจนต์ที่เน้นการทำงานในเครื่อง และเป็นทีมผู้ช่วย AI ที่ทำงานร่วมกัน บอก **Commander** ว่าต้องการทำอะไร: มันจัดการงานได้หลายอย่างด้วยตัวเอง สำหรับงานที่ใหญ่ขึ้น มันจะแบ่งงานเป็นขั้นตอนแล้วประสานเอเจนต์เฉพาะทางกับเอเจนต์เขียนโค้ดและเอเจนต์ส่วนตัวที่คุณใช้อยู่แล้ว ได้แก่ **Claude Code, Codex, OpenCode, OpenClaw และ Hermes-Agent**.

Orkas ออกแบบมาเพื่อให้โปรเจกต์เดินหน้าต่อ ไม่ใช่แค่ตอบคำถามครั้งเดียว **โปรเจกต์** เก็บเป้าหมาย กฎ หน่วยความจำ และไฟล์ไว้ด้วยกัน จึงเริ่มแชตใหม่แล้วทำงานต่อได้ทันที **รายการงาน** ใช้แบ่งงานให้คนและเอเจนต์ เมื่อเปิด **Auto-advance** ทีมจะรับงานถัดไปเอง ส่วน **ระบบอัตโนมัติตามกำหนดเวลา** ทำงานซ้ำได้ทุกชั่วโมง ทุกวัน ทุกสัปดาห์ หรือทุกเดือน ข้อมูลทั้งหมดจะเก็บอยู่ในคอมพิวเตอร์ของคุณ เมื่อทำงานเสร็จ ระบบจะส่งผลลัพธ์กลับมาให้คุณตรวจสอบ คุณจึงวางใจให้ Orkas ช่วยดูแลงานที่ธุรกิจของคุณต้องเดินหน้าต่อเนื่องได้

## สิ่งทีมงานส่ง

- **วิดีโอ เสียงเสียงและภาพ** — ️ VideoStudio, VoiceStudio, ImageStudio
- **รายงานการวิจัย, การตรวจสอบ SEO และการวิเคราะห์ตลาด** — ️ DeepResearcher, SeoGeoAgent, StockAnalyzer
- **สถานะการเขียน บทความ ข่าวสารและกระจกภาพ** — ️ ContentWriter, PptMaker
- **เว็บไซต์, UI และโค้ด** — ️ UIDesigner, ProductDeveloper
- **ไฟล์ Word, Excel, PowerPoint และ PDF** — ️ OfficeWorker

### สร้างคลิปที่อ้างอิงด้วยเนื้อหาของคุณเอง

**VideoStudio** ใช้โครงเรื่อง รูปแบบภาพ และจังหวะตัดต่อจากวิดีโอยอดนิยมเป็นแนวทาง แล้วนำสินค้า ข้อความ และสื่อของคุณมาสร้างวิดีโอใหม่ เมื่อคุณส่งไฟล์วิดีโอต้นแบบและสื่อของคุณให้ เอเจนต์จะวิเคราะห์ช่วงเปิด ลำดับข้อมูล จังหวะภาพ และข้อความชวนลงมือทำ จากนั้นระบุสิ่งที่จะเก็บไว้หรือเปลี่ยนก่อนลงมือผลิต

วิธีนี้เหมาะกับวิดีโออธิบายด้วยข้อความเคลื่อนไหว การสาธิต SaaS หรือแอป และการทำโฆษณาใหม่จากสื่อสินค้าที่มีอยู่ ข้อความ คำบรรยาย เสียงพากย์ และคลิปที่สร้างแยกกันสามารถแก้ไขทีละส่วนได้ แต่หากข้อความฝังอยู่ในภาพที่ AI สร้างขึ้น ต้องแก้ที่ภาพนั้น

> “ใช้ reference.mp4 เป็นแนวทางทำวิดีโอโปรโมตแนวตั้ง 30 วินาที คงช่วงเปิดที่ดึงดูดความสนใจ รูปแบบตัวอักษร และจังหวะไว้ แต่เปลี่ยนมาใช้สินค้ากับวิดีโอบันทึกหน้าจอของฉัน ขอดูผลวิเคราะห์และแผนการผลิตก่อน”

ต้องใช้ไฟล์วิดีโอที่เอเจนต์อ่านได้ ยังไม่มีฟังก์ชันดาวน์โหลดวิดีโอจากลิงก์แชร์บนโซเชียลมีเดีย และไม่รับประกันว่าจะทำซ้ำการเคลื่อนกล้องหรือการแสดงของคนจริงได้อย่างแม่นยำ หรือให้ภาพตรงกันทุกเฟรม ดู[ขั้นตอนการสร้างวิดีโอตามต้นแบบ](./resources/builtin/marketplace/agents/79df9cc89f5f/skills/video-craft/references/reference-recreation.md)สำหรับรายละเอียด

## ทํางานไปเรื่อยๆ

การทํางานหนึ่งคือการเริ่มต้นที่ดี ออร์ก้าถูกสร้างเพื่องานที่ยังคงดําเนิน

- **โครงการ** — งามและกฎ ความจํา และไฟล์ ที่การพูดคุยในโครงการทุกครั้งเริ่มต้นจาก
- **การทําหน้าที่และการอัตโนมัติ** — ✓ ทุกโครงการมีรายการของคนและเจ้าหน้าที่ที่จะทํา โดยกับ Auto-Advance เปิด, ทีมงานจะเก็บรายการต่อไปเองและนํางานเสร็จกลับมาเพื่อการรีวิวของคุณ
- **ระบบอัตโนมัติตามกำหนดเวลา** — ตั้งให้ทำงานทุกชั่วโมง ทุกวัน ทุกสัปดาห์ หรือทุกเดือนได้ Orkas ทำงานบนคอมพิวเตอร์ของคุณ ตั้งแต่รุ่น 1.9 เมื่อคอมพิวเตอร์ออกจากโหมดพักหรือเมื่อเปิด Orkas ระบบอัตโนมัติแต่ละรายการจะทำย้อนหลังเฉพาะงานล่าสุดที่พลาดไปในช่วง 12 ชั่วโมงก่อนหน้า
- **เครื่องเชื่อมต่อ** — ✓ Gmail, Google Calendar, Sheets and Drive, Notion, Slack, Shopify, Stripe และอื่นๆ อีกมากมาย โดยปกติ Orkas ถามก่อนส่ง, โพสต์หรือลบอะไร
- **แอปต์** — ️อธิบายเครื่องมือ และ Orkas สร้างมันเป็นแอพท้องถิ่นภายในแอปตั๊ปโต๊ะทํางาน ในแอพพพัคเกจการจ่ายเงินยังสามารถตีพิมพ์มันเป็นแอพเว็บที่มีลิงค์สาธารณะ
- **โครงการร่วมกัน** — *(แอพพพับ)*invite a teammate or VA, และให้งานทุกๆงานไปกับคนหรือตัวแทน

- **เก็บข้อมูลในเครื่องเป็นหลัก** — แชต ไฟล์ คลังความรู้ และเอเจนต์ที่กำหนดเองจะเก็บในเครื่องโดยค่าเริ่มต้น รุ่นติดตั้งเลือกเปิดการซิงก์บนคลาวด์ได้ หากใช้คีย์ของตัวเอง เครื่องจะส่งคำขอไปยังผู้ให้บริการโดยตรง ส่วนโมเดล Orkas ในตัวใช้บริการที่ Orkas ดูแล
- **ทุกรุ่นเปลี่ยนเวลา** — Commanderและเจ้าหน้าที่ในตัวแบ่งปันการตั้งแบบเดียวกัน: รูปแบบ Orkas ในตัว, ผู้ให้บริการของคุณเอง, หรือจุดปลายทางท้องถิ่น. เจ้าหน้าที่ CLI นอกรักษาการตั้งแบบของพวกเขาเอง.
- **เจ้าหน้าที่ที่ดีขึ้น** — ผู้นําแต่ละตัวถือรักษาความสามารถและความทรงจําส่วนตัว การตรวจสอบหลังวิจัยวิจัยการทํางานใหม่เมื่อแอพพนั้นว่าง และสามารถปรับปรุงการประเมินตนเอง, วิธีการใช้ได้อีกครั้งและทักษะที่เรียนรู้
- **แหล่งเปิด ไม่มีกล่องดํา** — อ่านสิทธิของออร์คาส และเจ้าหน้าที่และทักษะทุกคน

## เริ่มเร็ว

อยากได้เครื่องติดตั้งแบบพัคเกจแทนมั้ย[ดาวน์โหลด](#ดาวน์โหลด)ณ ปัจจุบันวิธีการทํางาน Orkas บน Linux:

**ความต้องการ**: Node 22.12+ · macOS / Windows 10+ / glibc 2.34+ Linux x64 หรือ arm64. ทําให้ Python 3 และรุ่น C / C ++ สร้างทุลโซ่ให้ใช้สําหรับการสร้างหลุดหลุดแบบจํากัดที่ไม่ธรรมดา

```bash
git clone https://github.com/Orkas-AI/Orkas.git
cd Orkas
./run.sh           # macOS / Linux
run.cmd            # Windows
```

การรันจากซอร์สบน Linux ต้องใช้ glibc 2.34 ขึ้นไป ไม่รองรับ Alpine หรือดิสทริบิวชันอื่นที่ใช้ musl เมื่อรันจากซอร์สครั้งแรก Orkas จะดาวน์โหลดและตรวจสอบรันไทม์ whisper.cpp สำหรับสถาปัตยกรรมของเครื่องและโมเดลหลายภาษาเพื่อถอดเสียงในเครื่อง

`run.sh` / `run.cmd` ติดตั้งต้นไม้พึ่งพัง npm และเตรียม Python, uv, Node, รูปแบบการติดตั้ง (~95 MB), OfficeCLI, FFmpeg, whisper.cpp และทรัพยากรรรรแบบพูดหลายภาษาในการเปิดตัวครั้งแรก การเริ่มต้นของ Linux จากนั้นตรวจสอบโหลดพื้นที่และเวลาทํางาน Whisper ภายใต้ ABI ของ Electron ก่อนเปิดแอพลิเคชั่น. แพ็กเกจ Python สำหรับ OCR และแพ็กเกจเฉพาะของแต่ละสกิลจะติดตั้งในสภาพแวดล้อมภายในเครื่องแบบแยกส่วนเมื่อใช้ฟีเจอร์นั้นครั้งแรก เมื่อเริ่มใช้งานครั้งแรก ระบบจะสร้างพื้นที่ทำงานใน `~/.orkas/` (macOS / Linux) หรือ `<smallest non-system drive>:\.orkas\` (Windows) จากนั้นเปิด **การตั้งค่า → ผู้ให้บริการ AI** เพื่อตั้งค่าคีย์ API หรือ OAuth

หากพบข้อผิดพลาดเกี่ยวกับการอ้างอิงแพ็กเกจเนทีฟ ให้ใช้ Node.js 24 LTS (ขั้นต่ำ 22.12.0) แล้วรัน
`npm run native:repair` จากไดเรกทอรีซอร์สโค้ดนี้ คำสั่งนี้จะกู้คืนแพ็กเกจเสริมที่เป็นตัวเลือก
จะซ่อมบิลด์ SQLite สำหรับ Electron และตรวจสอบ SQL กับ sqlite-vec นอกจากนี้
ยังเตรียมรันไทม์ Node ที่มาพร้อมแอปและตรวจสอบ sharp ในโพรเซสแยกก่อนรายงานว่าสำเร็จ
ใช้งาน`npm run native:check`สําหรับการตรวจสอบโดยไม่มีการติดตั้ง
ดู[สกรีนการตรวจสอบความพึ่งพาพื้นฐาน](./scripts/verify-native-dependencies.cjs)สําหรับการตรวจสอบที่ทํา

Commanderจัดการงานทั่วไปเอง และมอบหมายให้ทํางานผู้เชี่ยวชาญผ่านเครื่องมือสามอย่าง

- **`dispatch_to`** เรียกเอเจนต์ที่ระบุชื่อ เมื่อได้รับผลลัพธ์แล้ว Commander จะทำงานต่อ คุณเลือกได้ว่าจะรอผลหรือให้ทำงานแบบอะซิงโครนัสแล้วแจ้ง Commander เมื่องานเสร็จ
- **`hand_off_to`** — ส่งงานที่เหลือให้เจ้าหน้าที่ชื่อ และจบการทํางานของCommanderปัจจุบัน เจ้าหน้าที่จะตอบเอง การต่อเนื่องทางเลือกจะทําให้เจ้าหน้าที่บัญชาการสามารถดําเนินงานต่อไปในครั้งที่กว้างขวาง
- **`run_worker`** — ทํางานแบบไม่ทราบชื่อ และแยกตัว และคืนผลส่วนตัว มันไม่ได้รับประวัติการพูดคุย หรือความสามารถของเจ้าหน้าที่ที่ได้รับชื่อ

การทํางานของผู้แทนที่ชื่อและคนทํางานที่ไม่ทราบชื่อ มีการควบคุมเวลาเดียวกันแยก[การดําเนินการส่ง](./src/main/features/group_chat/bus.ts)และ[ปิดการประกอบ](./src/main/util/locks.ts).

### การจัดการสถานการณ์

การใช้เวลาในการทํางานของตารางการใช้งานที่ใช้งานกับความสามารถในการเข้าของแบบที่เลือก, การบัญชีสําหรับคําสั่ง, เครื่องมือและสถานการณ์การทํางานที่คงอยู่. การสื่อสารเสร็จสิ้นใช้หน้าต่างประวัติศาสตร์ล่าสุดที่จํากัด; งานที่ทํางานยาวนานใช้จุดตรวจสอบเพื่อประมวลสารกระบวนการก่อนหน้านี้โดยยังคงทํางานล่าสุด. การอ่านไฟล์, การเปลี่ยนแปลงไฟล์ และการดําเนินการบัญชาการยังมีบันทึกโครงสร้างที่สามารถรอดพ้นการคอมเพชิดในสภาพ

ดูสิ[งบประมาณในสภาพ](./src/core-agent/src/agent/context-budget.ts), [ประวัติการประชุมและจุดตรวจสอบ](./src/core-agent/src/agent/session.ts)และ[รายงานพื้นที่ทํางาน](./src/core-agent/src/agent/workspace-state.ts).

### ความ จํา และ ห้องสมุด

บันทึกที่มีความยั่งยืนเก็บความชอบของผู้ใช้, ข้อมูลโครงการและความรู้ที่สามารถนําไปใช้ได้อีกครั้งของตัวแทนแต่ละตัวในระยะที่แยกกัน. บันทึกเหล่านี้แตกต่างจากอัตราบันทึกเอกสารของห้องสมุดและประวัติการพูดคุยที่เก็บไว้

คลังเอกสารแยกเอกสารเป็นย่อหน้าและสร้างดัชนีเวกเตอร์ SQLite ในเครื่อง โมเดลฝังเวกเตอร์ทำงานบนคอมพิวเตอร์ของคุณ เอเจนต์ใช้เครื่องมือ `library` เพื่อดูรายการไฟล์ ค้นหาข้อความที่เกี่ยวข้อง และอ่านต้นฉบับจากคลังส่วนกลางหรือคลังของโปรเจกต์ปัจจุบัน ส่วนแชตเก่าค้นหาแยกด้วย `chat_history`

ดูสิ[ความจําระยะ](./src/main/features/memory.ts), [การขอกสาร](./src/main/util/file_to_chunks.ts), [เครื่องมือห้องสมุด](./src/main/model/core-agent/kb-tools.ts)และ[การเรียกคืนการพูดคุย](./src/main/model/core-agent/chat-history-tools.ts).

## FAQ

**ออร์คาสคืออะไร?**
Orkas เป็นแอปเดสก์ท็อปโอเพนซอร์ส (MIT) ที่ให้เอเจนต์หลายตัวทำงานร่วมกันและเน้นทำงานในเครื่อง Commander แยกเป้าหมายเป็นรายการงาน แล้วประสานเอเจนต์เฉพาะทางในตัว 16 ตัว รวมถึง Claude Code, Codex, OpenCode, OpenClaw และ Hermes-Agent เพื่อส่งมอบไฟล์ที่เสร็จแล้ว

**ฉันต้องการกุญแจ API?**
ไม่จำเป็น รุ่นติดตั้งมาพร้อมเครดิต 500 หน่วยสำหรับโมเดล Orkas ในตัว เมื่อใช้หมดแล้ว คุณซื้อเครดิต เลือกแพ็กเกจแบบชำระเงิน หรือเพิ่มคีย์ของผู้ให้บริการที่คุณใช้เองได้ ผู้ให้บริการจะคิดค่าบริการแยกต่างหาก

**Orkas เป็นโมเดลภาษาขนาดใหญ่ (LLM) ที่ทำงานในเครื่องหรือไม่**
ไม่ใช่ Orkas ทำงานบนคอมพิวเตอร์ของคุณและเรียกใช้โมเดลที่คุณเลือก ไม่ว่าจะเป็นโมเดล Orkas ในตัว โมเดลที่เชื่อมต่อด้วยคีย์ API ของคุณเอง หรือโมเดลผ่านเอนด์พอยต์ในเครื่อง Orkas ทำหน้าที่ประสานงานเอเจนต์และเครื่องมือ ไม่ใช่ตัวโมเดลเอง

**ออร์คาสสามารถตอบคําถามจากเอกสารของฉันได้ด้วยคําอ้างอิงหรือไม่**
ใช่. เพิ่มเติม PDF และเอกสารไปยังห้องสมุดในพื้นที่ของคุณ; Orkas สามารถค้นหาและตอบด้วยการอ้างอิงเพื่อแหล่งฉบับ, เพื่อให้คุณสามารถเปิดต้นฉบับและตรวจสอบ. อินเด็กซ์ถูกสร้างขึ้นบนเครื่องของคุณ.

**ฉันสามารถใช้ตัวอย่างในพื้นที่ เช่น โอลาม่า หรือ LM Studio ได้มั้ย**
ได้ ไปที่ **การตั้งค่าบัญชี → โมเดล → แชต → เพิ่มโมเดล → กำหนดเอง** เลือก **รองรับ OpenAI** หรือ **รองรับ Anthropic** กรอก URL ฐาน รหัสโมเดลที่ถูกต้อง และคีย์ API จากนั้นเลือกโมเดลที่บันทึกไว้ในเมนูเลือกโมเดลของงาน

**เซ็นต์ API และข้อมูลของผมถูกเก็บไว้ที่ไหน**
โดยค่าเริ่มต้น ข้อมูลและคีย์จะเก็บอยู่ในเครื่องของคุณ คีย์ของผู้ให้บริการที่คุณนำมาใช้เองจะเข้ารหัสในเครื่องและไม่ซิงก์ขึ้นคลาวด์ เมื่อใช้คีย์ของตัวเอง ระบบจะเรียกใช้โมเดลจากเครื่องของคุณไปยังผู้ให้บริการโดยตรง ส่วนโมเดล Orkas ในตัวใช้บริการที่ Orkas ดูแล หากเปิดใช้การซิงก์บนคลาวด์หรือโปรเจกต์ที่แชร์ในรุ่นติดตั้ง ข้อมูลที่เลือกจะเก็บบนเซิร์ฟเวอร์ของ Orkas [ความปลอดภัยและการจัดการข้อมูล →](https://orkas.ai/security/?source=gh-orkas)

**ออร์คาสทํางาน offline?**
การสร้างแหล่งสามารถทํางานได้อย่างเต็มที่ offline กับจุดปลายของรุ่นในพื้นที่ แอพพิกซ์ต้องเข้าใช้งาน และรุ่นเมฆต้องการการเชื่อมต่อเครือข่าย

**มันยังทํางานได้มั้ย ตอนที่คอมพิวเตอร์ฉันปิด?**
ไม่ทำงาน Auto-advance และระบบอัตโนมัติตามกำหนดเวลาต้องให้คอมพิวเตอร์ทำงานและเปิด Orkas อยู่ ตั้งแต่รุ่น 1.9 เมื่อคอมพิวเตอร์ออกจากโหมดพักหรือเมื่อเปิด Orkas ระบบอัตโนมัติแต่ละรายการจะทำย้อนหลังเฉพาะงานล่าสุดที่พลาดไปในช่วง 12 ชั่วโมงก่อนหน้า

**ฉันสามารถสร้างและตีพิมพ์แอปได้มั้ย**
ใช่ แอพลิเคชั่นในพื้นที่ที่ใช้งานภายใน Orkas เป็นฟรี การตีพิมพ์แอปพลิเคชันเว็บไปยังลิงค์สาธารณะต้องมีแผนการจ่ายเงิน (Lite 5, Pro 8, Max 15 แอปลิเคชัน) และแอปพลิเกชันเว็บที่ตีพิมพัยไม่ได้รวมถึงความสามารถทั้งหมดที่มีอยู่ใน Orkas

**ฉันต้องการบัญชีของออร์คาสไหม?**
แอพพเพคเกดเดสโต๊ปขอให้คุณเข้าใช้งานเมื่อคุณเปิดตัวครั้งแรก. แหล่งสร้างในสํานักเก็บข้อมูลนี้ไม่มีชั้นบัญชีเลย

**ออร์คาสสามารถdriveเคลื่อนคล๊อด โคด และเจ้าหน้าที่ CLI อีกคนได้มั้ย**
ใช่. Orkas สามารถdriveเคลื่อนตัวแทน CLI ภายนอกห้าตัวเป็นกระบวนการรองพื้นที่ หน่วยงานเขียนโค้ด Claude Code, Codex และ OpenCode รวมถึงตัวแทนส่วนตัว OpenClaw และ Hermes-Agent และโครงการเปิดแหล่ง เช่น HyperFrames ทั้งหมดถูกกํากับจากจอเดียวกัน

**Orkas ต่างจาก Claude Code, Codex, CrewAI และ LangChain อย่างไร?**
Claude Code และ Codex เป็นเอเจนต์เขียนโค้ดที่ใช้ร่วมกันในทีม Orkas ได้ ส่วน CrewAI และ LangChain เป็นเฟรมเวิร์กที่เน้นการเขียนโค้ด Orkas เป็นแอปเดสก์ท็อปโอเพนซอร์สที่ให้ Commander ประสานงานเอเจนต์เฉพาะทางและเอเจนต์ CLI คุณเลือกผู้ให้บริการโมเดลได้หลายราย และระบบเก็บข้อมูลกับคีย์ไว้ในเครื่องโดยค่าเริ่มต้น [ดูการเปรียบเทียบทั้งหมด](https://orkas.ai/compare/?source=gh-orkas)

**โปรแกรมไหนที่ออร์คาสสนับสนุน?**
มีตัวติดตั้งสำหรับ macOS 12+ (Apple Silicon และ Intel) และ Windows 10+ ส่วน Linux x64/arm64 ที่ใช้ glibc 2.34+ ยังไม่มีตัวติดตั้งและต้องรันจากซอร์ส ครั้งแรกที่เปิดแอปจะเตรียมรันไทม์ whisper.cpp ตามเวอร์ชันที่กำหนดสำหรับถอดเสียงในเครื่อง ไม่รองรับ Alpine และดิสทริบิวชันอื่นที่ใช้ musl การรันจากซอร์สต้องใช้ Node 22.12+ ส่วน Python 3 และชุดเครื่องมือบิลด์ C/C++ จำเป็นเฉพาะเมื่อแพ็กเกจ npm แบบเนทีฟไม่มีไบนารีสำเร็จรูปที่เข้ากันได้และต้องบิลด์ใหม่ในเครื่อง

**ออร์คาเป็นอิสระและเปิดแหล่ง?**
ใช่ แอปใช้สัญญาอนุญาต MIT และใช้งานได้ฟรี รุ่นติดตั้งมาพร้อมเครดิต 500 หน่วยสำหรับโมเดล Orkas ในตัว แพ็กเกจแบบชำระเงินเริ่มที่ $11.99 ต่อเดือน เพิ่มเครดิตรายเดือน การซิงก์บนคลาวด์ จำนวนโปรเจกต์ที่แชร์ และการเผยแพร่เว็บแอป หากใช้คีย์ของตัวเอง ผู้ให้บริการจะคิดค่าบริการตามการใช้งานโมเดล โดย Orkas ไม่คิดเพิ่ม [ราคา →](https://orkas.ai/pricing/?source=gh-orkas)
