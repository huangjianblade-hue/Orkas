### إعادة إنشاء فيديو مرجعي بمحتوى خاص بك

**VideoStudio** يمكن إعادة إنشاء هيكل الترويدي فيديو الفيروسي، وأسلوب البصري وتيرة التحرير باستخدام منتجك، والمنشورات والصور. قم بتزويد ملف الفيديو المرجعي وأصولك: يقوم الوكيل بتحليل الرمز، وتسلسل المعلومات، والضربات البصرية ودعوة إلى العمل، ثم يقدم ما يجب الحفاظ عليه وما يجب استبداله قبل الإنتاج.

هذا يعمل بشكل أفضل لموضحات الحركة الجرافية أو عرضات SaaS أو تطبيقات التجربة ، وإعلانات المنتجات التي تم بناؤها من لقطاتك الحالية. يمكن مراجعة النص المصدر محلياً والقوائم والنقل والمقاطع بشكل منفصل ؛ يتطلب النص الذي يتم إخبئه في لقطات مصنوعة من AI تغيير تلك اللقطات.

> "استخدم مرجع.mp4 كمرجع لترويج عمودي لمدة 30 ثانية. حافظ على خطة الخطوط والخطوط النصية، واستبدل المحتوى بتسجيلات منتج وأكشافي، وأرني التفكيك والخطة أولاً".

البدء بملف الفيديو الذي يستطيع الوكيل قراءته؛ لا يتم تحميل الروابط المشتركة على المنصات الاجتماعية. لا تضمن الحركات الكاميرات الدقيقة والأداء البشري ومطابقة الإطار بالإطار. انظر[سير العمل الإرجاني والتسلية](./resources/builtin/marketplace/agents/79df9cc89f5f/skills/video-craft/references/reference-recreation.md).

## بداية سريعة

هل تريد إصدار محمول بدلاً من ذلك؟[تحميل](#تحميل)أعلاه. لتنفيذ من المصدر

**المتطلبات**: Node 22.12+ · macOS / Windows 10 + / glibc 2.34+ Linux x64 أو arm64. الحفاظ على Python 3 وسلسلة أدوات بناء C / C ++ متاحة للخلفية غير الشائعة من بناء المصدر في الوحدة الأصلية.

```bash
git clone https://github.com/Orkas-AI/Orkas.git
cd Orkas
./run.sh           # macOS / Linux
run.cmd            # Windows
```

يتطلّب التشغيل من المصدر على Linux الإصدار glibc 2.34 أو أحدث. لا يدعم Orkas توزيعة Alpine أو التوزيعات الأخرى القائمة على musl. عند أول تشغيل من المصدر، يُنزّل وقت تشغيل whisper.cpp المناسب لمعمارية الجهاز والنموذج متعدد اللغات ويتحقق منهما لإتاحة تحويل الكلام إلى نص محلياً.

عند أول تشغيل باستخدام `run.sh` / `run.cmd`، تُثبَّت تبعيات npm المحددة في ملف القفل، وتُجهَّز الإصدارات المحددة من Python وuv وNode ونموذج التضمين (نحو 95 ميغابايت) وOfficeCLI وFFmpeg وwhisper.cpp ونموذج الكلام متعدد اللغات. في Linux، يتحقق برنامج التشغيل من توافق الوحدات الأصلية للمنصة وبيئة تشغيل Whisper مع ABI الخاص بـ Electron قبل فتح التطبيق. وتُثبَّت حزم Python الخاصة بالتعرّف البصري على الحروف (OCR) وبكل مهارة في بيئة محلية معزولة عند استخدام الميزة المعنية لأول مرة. ينشئ التطبيق عند تشغيله لأول مرة مساحة عمل في `~/.orkas/` (macOS / Linux) أو `<smallest non-system drive>:\.orkas\` (Windows). بعد ذلك، انتقل إلى **الإعدادات → موفّرو الذكاء الاصطناعي** لإعداد مفتاح API أو OAuth.

عند حدوث خطأ في الاعتماديات الأصلية، استخدم Node.js 24 LTS (الحد الأدنى 22.12.0) وشغّل من هذا المجلد
`npm run native:repair`. يستعيد هذا الأمر الاعتماديات الاختيارية،
ويصلح SQLite الخاص بـ Electron ويتحقق من SQL وsqlite-vec. كما
يهيّئ بيئة تشغيل Node المرفقة ويتحقق من sharp في عملية مستقلة قبل الإبلاغ عن النجاح.
الاستخدام`npm run native:check`للفحص بدون تركيب.
انظروا[نص التحقق من الاعتماد الأصلي](./scripts/verify-native-dependencies.cjs)للتحققات التي تمت.

## كيف يعمل

### توجيه المهام

الCommander يقوم بنفسه بالعمل العام ويمنح المهنيين العمل من خلال ثلاثة أدوات:

- **`dispatch_to`** — يدير وكيلًا مسمّى ويرجع نتيجه لمتواصلة العمل. يمكن أن ينتظر النتيجة أو يدير بشكل غير متزامن ويعلم الCommander عندما تنتهي المهمة.
- **`hand_off_to`** — يُنقل العمل المتبقي إلى عميل مسمّى ويقضي دور الCommander الحالي. يقوم العميل بإعطاء إجابته الخاصة؛ ويتيح الاستمرار الاختياري للقائد استئناف مهمة أوسع بعد ذلك.
- **`run_worker`** — يدير مهمة فرعية مجهولة و معزولة ويستعيد نتيجة خاصة. لا يتلقى تاريخ المحادثة أو مهارات العميل المسمى.

مهام العملاء المسمّين والموظفين المجهولين لديهم مراقبة متزامنة منفصلة.[تنفيذ الإرسال](./src/main/features/group_chat/bus.ts)و[قفلات التنفيذ](./src/main/util/locks.ts).

### إدارة السياق

يستخدم الحوار المكتمل نافذة محددة من التاريخ الحديث؛ وتستخدم المهام النشطة طويلة نقاط تفتيش لتجميد رسائل العملية السابقة مع الاحتفاظ بالعمل الأخير. قراءة الملفات وتغييرات الملفات وتنفيذ الأوامر لديها أيضا سجلات مهيكلة يمكن أن تتعافى من ضغط السياق.

انظر[الميزانيات السياقية](./src/core-agent/src/agent/context-budget.ts), [تاريخ الجلسة ومواقع التفتيش](./src/core-agent/src/agent/session.ts)و[سجلات مساحة العمل](./src/core-agent/src/agent/workspace-state.ts).

### الذاكرة والمكتبة

تُحفظ الملاحظات الدائمة تفضيلات المستخدمين وحقيقة المشروع ومعرفة كل وكيل قابلة لإعادة الاستخدام في نطاقات منفصلة. هذه الملاحظات تختلف عن فهرس الوثائق في المكتبة وتاريخ المحادثات المخزن.

تستخرج المكتبة فقرات المستندات وتُنشئ فهرس متجهات محلياً باستخدام SQLite. يعمل نموذج التضمين على حاسوبك. يستخدم الوكلاء `library` لسرد الملفات والبحث عن المقاطع ذات الصلة وقراءة النص الأصلي في المكتبة العامة أو مكتبة المشروع الحالي. ويُبحث عن المحادثات السابقة بصورة منفصلة باستخدام `chat_history`.

انظر[الذاكرة المحددة](./src/main/features/memory.ts), [استخراج الوثائق](./src/main/util/file_to_chunks.ts), [أدوات المكتبة](./src/main/model/core-agent/kb-tools.ts)و[استرداد المحادثة](./src/main/model/core-agent/chat-history-tools.ts).

تضبط أقفال الجلسات وحدود التزامن عدد المهام الجارية بالتوازي. وتحد ضوابط عدد جولات الأدوات، ونقاط التحقق من التقدم، وفحوص الاستدعاءات المكررة، ومراقبة الخمول حسب المرحلة من حالات التعطل أو التكرار. يمكن تتبع مهمة كل وكيل مُسمّى وإلغاؤها على حدة. قبول المهمة أو وضعها في قائمة الانتظار لا يعني اكتمالها.

## الأسئلة الشائعة

**ما هو Orkas؟**
Orkas تطبيق مكتبي مفتوح المصدر (MIT) ينسّق عمل عدة وكلاء ويعطي الأولوية للعمل المحلي. يُقسّم Commander هدفك إلى مهام، وينسّق عمل 16 وكيلاً متخصصاً مدمجاً إلى جانب Claude Code وCodex وOpenCode وOpenClaw وHermes-Agent لتسليم الملفات النهائية.

**هل أحتاج مفتاح إيه بي؟**
لا. تشمل النسخة القابلة للتثبيت 500 وحدة رصيد لنموذج Orkas المدمج. بعد نفاد الرصيد يمكنك شراء رصيد إضافي أو اختيار خطة مدفوعة أو إضافة مفتاح مزوّدك؛ ويحتسب المزوّد رسومه بصورة منفصلة.

**هل Orkas نموذج لغوي كبير (LLM) يعمل محلياً؟**
لا. يعمل Orkas على حاسوبك ويستدعي النموذج الذي تختاره: نموذج Orkas المدمج، أو نموذجاً تتصل به باستخدام مفتاح API الخاص بك، أو نقطة نهاية لنموذج محلي. مهمته تنسيق عمل الوكلاء والأدوات؛ فهو ليس نموذجاً في حد ذاته.

**هل يستطيع (Orkas) الإجابة على الأسئلة من وثائقي، مع اقتباسات؟**
نعم. إضافة ملفات PDF والوثائق إلى مكتبة محلية الخاصة بك؛ Orkas يمكن البحث في هذه الملفات والرد مع اقتباسات إلى المقاطع المصدرة، حتى تتمكن من فتح الأصلي والتحقق. يتم بناء المؤشر على جهازك.

**هل يمكنني استخدام نماذج محلية مثل (أولاما) أو (إلم ستوديو) ؟**
نعم. افتح **إعدادات الحساب ← النماذج ← المحادثة ← إضافة نموذج ← مخصص**، واختر **متوافق مع OpenAI** أو **متوافق مع Anthropic**. أدخل عنوان URL الأساسي ومعرّف النموذج بدقة ومفتاح API، ثم اختر النموذج المحفوظ من أداة اختيار النموذج في المهمة.

**أين يتم تخزين مفاتيح و بياناتي؟**
تُحفَظ البيانات والمفاتيح على حاسوبك افتراضياً. تُشفَّر مفاتيح مزوّد الخدمة الخاصة بك محلياً ولا تُزامَن مع السحابة. عند استخدام مفتاحك، تُرسَل طلبات النموذج من حاسوبك مباشرةً إلى المزوّد؛ أما نموذج Orkas المدمج فيستخدم خدمة تديرها Orkas. في النسخة القابلة للتثبيت، يؤدي استخدام المزامنة السحابية الاختيارية أو المشاريع المشتركة إلى تخزين البيانات المحددة على خوادم Orkas. [الأمان ومعالجة البيانات ←](https://orkas.ai/security/?source=gh-orkas)

**هل تعمل (أوركا) خارج الاتصال؟**
يمكن للنسخة المشغّلة من المصدر العمل دون اتصال عند استخدام نقطة نهاية لنموذج محلي. تتطلب النسخة القابلة للتثبيت تسجيل الدخول، وتتطلب استدعاءات النماذج السحابية اتصالاً بالإنترنت.

**هل يستمر في العمل عندما يكون جهاز الكمبيوتر الخاص بي مغلق؟**
لا. يتطلب التقدم التلقائي والأتمتة المجدولة أن يظل الحاسوب مستيقظاً وأن يكون Orkas قيد التشغيل. بدءاً من الإصدار 1.9، عند استئناف الحاسوب من وضع السكون أو تشغيل Orkas، تستدرك كل أتمتة آخر تشغيل فائت فقط ضمن الساعات الـ12 السابقة.

**هل يمكنني بناء ونشر التطبيقات؟**
نعم. التطبيقات المحلية التي تعمل داخل Orkas مجانية. يتطلب نشر تطبيق ويب برابط عام خطة مدفوعة: تتيح Lite نشر 5 تطبيقات، وPro نشر 8، وMax نشر 15. ولا تتضمن تطبيقات الويب المنشورة كل الإمكانات المتاحة في تطبيق Orkas المكتبي.

**هل أحتاج حساباً من الـ (أوركا) ؟**
تتطلب النسخة القابلة للتثبيت تسجيل الدخول عند تشغيلها أول مرة. النسخة المشغّلة من مصدر هذا المستودع لا تتضمن وحدة للحسابات، بل تفتح التطبيق مباشرةً.

**هل يستطيع Orkas تشغيل Claude Code وغيره من وكلاء سطر الأوامر؟**
نعم. يمكن لـ Orkas تشغيل خمسة وكلاء خارجيين كعمليات فرعية محلية: Claude Code وCodex وOpenCode للبرمجة، وOpenClaw وHermes-Agent للاستخدام الشخصي. ويمكنه أيضاً ربط أدوات مفتوحة المصدر مثل HyperFrames وتنسيق العمل من المحادثة نفسها.

**كيف يختلف Orkas عن Claude Code وCodex وCrewAI وLangChain؟**
Claude Code وCodex وكيلان للبرمجة، ويمكن تشغيلهما معاً ضمن فريق Orkas. أما CrewAI وLangChain فهما إطاران يعتمدان على كتابة الشيفرة. Orkas تطبيق مكتبي مفتوح المصدر ينسّق فيه Commander عمل الوكلاء المتخصصين ووكلاء سطر الأوامر. يمكنك الاختيار من بين مزوّدي نماذج مختلفين، وتُحفَظ البيانات والمفاتيح محلياً افتراضياً. [عرض المقارنات الكاملة](https://orkas.ai/compare/?source=gh-orkas)

**أي منصات تدعمها (أوركا) ؟**
