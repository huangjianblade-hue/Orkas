# Orkas

**Uma equipe de agentes de IA em código aberto no seu desktop transforma os seus objetivos em trabalho acabado e mantém-no em movimento.**

O Orkas é um aplicativo de desktop multiagente de código aberto (MIT) que prioriza a execução local e reúne uma equipe de assistentes de IA que trabalham juntos. Conte ao **Commander** o que você precisa: ele resolve muitas tarefas sozinho e, nos trabalhos maiores, divide o trabalho em etapas e aciona agentes especializados e os agentes pessoais e de programação que você já usa — **Claude Code, Codex, OpenCode, OpenClaw e Hermes-Agent** — para trabalhar em equipe.

O Orkas ajuda a manter projetos em andamento, não só a responder a uma pergunta. Os **projetos** reúnem objetivos, regras, memória e arquivos para que cada conversa retome o trabalho anterior. Você pode distribuir **tarefas** entre pessoas e agentes. Com o **Auto-advance**, a equipe assume a próxima tarefa por conta própria. As **automações agendadas** repetem rotinas a cada hora, dia, semana ou mês. Todos os seus dados ficam no seu computador, e você recebe os resultados para revisar. Assim, você pode confiar à Orkas as tarefas do seu negócio que exigem acompanhamento contínuo.

### Recrear um vídeo de referência com o seu próprio conteúdo

**VideoStudio** Pode recriar a estrutura narrativa, estilo visual e ritmo de edição de um vídeo viral usando seu próprio produto, roteiro e imagens. Forneça um arquivo de vídeo de referência e seus ativos: o agente analisa o gancho, ordem de informações, batidas visuais e chamada à ação, depois propõe o que preservar e o que substituir antes da produção.

Isso funciona melhor para explicadores de motion-graphic, SaaS ou demonstrações de aplicativos e anúncios de produtos construídos a partir de suas imagens existentes.

> "Use o reference.mp4 como referência para uma promoção vertical de 30 segundos. Mantenha seu gancho, tipografia e ritmo, substitua o conteúdo com meu produto e gravações de tela, e me mostre a descomposição e planejar primeiro".

Comece com um arquivo de vídeo que o agente possa ler; download de links compartilhados em plataformas sociais não está incorporado.[fluxo de trabalho de referência e recreação](./resources/builtin/marketplace/agents/79df9cc89f5f/skills/video-craft/references/reference-recreation.md).

## Mantém o trabalho em movimento

Uma tarefa é um bom começo.

- **Projeto** — metas e regras, memória e arquivos que todas as conversas no projeto começam a partir, para que você nunca abrevia do zero.
- **Ações e Avanços Automáticos** — cada projeto tem uma lista de tarefas para pessoas e agentes; com o Auto-advance, a equipe pega o próximo item por conta própria e traz o trabalho acabado para sua revisão.
- **Automações agendadas** — Execute tarefas a cada hora, dia, semana ou mês. O Orkas roda no seu computador. A partir da versão 1.9, quando o computador sai do modo de suspensão ou o Orkas é iniciado, cada automação recupera somente a execução perdida mais recente das últimas 12 horas.
- **Conectores** — Gmail, Google Calendar, Sheets and Drive, Notion, Slack, Shopify, Stripe e muitos outros.
- **Aplicativos** — Descreva a ferramenta de que você precisa e o Orkas cria um aplicativo local que roda dentro do aplicativo para desktop. Na versão instalável, assinantes de um plano pago também podem publicá-lo como aplicativo web com um link público.
- **Projetos compartilhados** (versão instalável) — Convide colegas ou assistentes virtuais e atribua cada tarefa a uma pessoa ou a um agente.

> [!NOTE]
> Os projetos compartilhados, a sincronização em nuvem e a publicação de aplicativos web estão apenas no pacote de aplicativos.**[baixar Orkas para macOS e Windows](https://orkas.ai/download/?source=gh-orkas&entry_point=github_readme&download=1)** (gratuito, com 500 créditos para começar).

## Começo rápido

Prefere usar um instalador? Consulte a seção [Download](#descarga). Para executar a partir do código-fonte:

**Requisitos**: Node 22.12+ · macOS / Windows 10+ / glibc 2.34+ Linux x64 ou arm64. Mantenha Python 3 e uma cadeia de ferramentas de construção C/C++ disponíveis para o incomum fallback de construção de código-fonte do módulo nativo.

```bash
git clone https://github.com/Orkas-AI/Orkas.git
cd Orkas
./run.sh           # macOS / Linux
run.cmd            # Windows
```

Para rodar o Orkas pelo código-fonte no Linux, é necessário ter glibc 2.34 ou mais recente. Não há suporte para Alpine nem para outras distribuições baseadas em musl. Na primeira execução pelo código-fonte, o Orkas baixa e verifica o ambiente de execução do whisper.cpp para a arquitetura do computador e o modelo multilíngue para transcrição de voz local.

Na primeira inicialização, `run.sh` / `run.cmd` instala as dependências do npm fixadas no arquivo de lock e prepara as versões definidas do Python, uv, Node, do modelo de embeddings (cerca de 95 MB), do OfficeCLI, do FFmpeg, do whisper.cpp e do modelo de fala multilíngue. No Linux, antes de abrir o aplicativo, a inicialização verifica os módulos nativos da plataforma e o runtime do Whisper com a ABI do Electron. Os pacotes Python de OCR e os específicos de cada Skill são instalados em ambientes locais isolados quando os respectivos recursos são usados pela primeira vez. A primeira inicialização cria um espaço de trabalho em `~/.orkas/` (macOS / Linux) ou `<smallest non-system drive>:\.orkas\` (Windows). Depois, abra **Configurações → Provedores de IA** para configurar uma chave de API ou OAuth.

Se ocorrer um erro nas dependências nativas, use o Node.js 24 LTS (versão mínima: 22.12.0) e execute
`npm run native:repair` neste diretório do código-fonte. O comando restaura as dependências opcionais,
repara a compilação do SQLite para Electron e verifica SQL e sqlite-vec. O comando
também prepara o runtime Node incluído e verifica sharp em um processo separado antes de informar que o reparo foi bem-sucedido.
Utilização`npm run native:check`para um cheque sem instalação.
Veja o[script de verificação de dependência nativa](./scripts/verify-native-dependencies.cjs)para os controlos efectuados.

## Como funciona

### Roteamento de tarefas

O Comandante encarrega-se do trabalho geral e delega o trabalho especializado através de três ferramentas:

- **`dispatch_to`** — Pode esperar o resultado ou correr assíncrono e notificar o Comandante quando a tarefa terminar.
- **`hand_off_to`** passa o trabalho restante para um agente identificado pelo nome e encerra o turno atual do Commander. Esse agente responde diretamente. Uma etapa de acompanhamento opcional permite que o Commander retome a tarefa mais ampla depois.
- **`run_worker`** — executa uma sub-tarefa anônima e isolada e retorna um resultado privado. Não recebe histórico de conversação ou habilidades de um agente nomeado.

As tarefas dos agentes nomeados e os trabalhadores anónimos têm controles de simultaneidade separados.[Implementação do envio](./src/main/features/group_chat/bus.ts)e[bloqueios de execução](./src/main/util/locks.ts).

### Gestão de contexto

O contexto de orçamentos de tempo de execução contra a capacidade de entrada utilizável do modelo selecionado, contabilização de pedidos, ferramentas e estado de tempo de execução persistente. Diálogo concluído usa uma janela limitada de história recente; tarefas ativas longas usam checkpoints para condensar mensagens de processo anteriores enquanto retêm trabalho recente. Leituras de arquivos, alterações de arquivo e execuções de comandos também têm registros estruturados que podem sobreviver à compactação de contexto.

Veja[orçamentos de contexto](./src/core-agent/src/agent/context-budget.ts), [História da sessão e pontos de controlo](./src/core-agent/src/agent/session.ts)e[Registros de espaço de trabalho](./src/core-agent/src/agent/workspace-state.ts).

### Memória e Biblioteca

As notas duráveis mantêm as preferências dos usuários, os fatos do projeto e o conhecimento reutilizável de cada agente em escopo separado.

A biblioteca separa documentos em parágrafos e cria um índice vetorial local em SQLite. O modelo de embeddings roda no seu computador. Com `library`, os agentes podem listar arquivos, localizar trechos relevantes e ler o conteúdo original na biblioteca geral ou na do projeto atual. As conversas anteriores são pesquisadas separadamente com `chat_history`.

Veja[Memória de alcance](./src/main/features/memory.ts), [Extração de documentos](./src/main/util/file_to_chunks.ts), [Ferramentas de biblioteca](./src/main/model/core-agent/kb-tools.ts)e[conversas de recuperação](./src/main/model/core-agent/chat-history-tools.ts).

### Limite de execução e recuperação

Os bloqueios de sessão e os limites de concurência ligam o trabalho paralelo. Orçamentos de rodada de ferramentas, pontos de controle de progresso, verificações repetidas de chamadas e vigilantes passivos conscientes de fase ajudam a conter corridas que impedem ou repetem o trabalho. As tarefas do agente nomeado podem ser rastreadas e canceladas individualmente; uma tarefa admitida ou em fila não é tratada como um resultado concluído.

Veja[orçamentos dos actores](./src/main/features/group_chat/actor-budgets.ts), o[tempo de execução do agente](./src/core-agent/src/agent/runner.ts)e o[adaptador de modelo de desktop](./src/main/model/core-agent/client.ts).

### Aprender com a atividade

A revisão em segundo plano examina novas atividades dos agentes quando o aplicativo está ocioso, respeitando intervalos e limites de execução. Pode atualizar a autoavaliação (`COMPETENCE.md`), os métodos reutilizáveis (`LEARNING_STRATEGIES.md`) ou as habilidades aprendidas, ou concluir que não há nada a salvar. A revisão é agendada conforme a atividade recente, não pelo número de tarefas concluídas.

Veja o[programação de reflexão](./src/main/features/reflection-orchestrator.ts)e[urgência de revisão](./src/core-agent/src/evolution/metacognition.ts).

## FAQ

**O que é Orkas?**
O Orkas é um aplicativo de desktop multi-agente local de código aberto (MIT). Seu Comandante transforma seu objetivo em tarefas e coordena 16 agentes especializados integrados  além de Claude Code, Codex, OpenCode, OpenClaw e Hermes-Agent  para entregar arquivos acabados.

**Preciso de uma chave API?**
Não. O versão instalável vem com 500 créditos para o modelo Orkas incorporado. Depois disso, compre créditos, escolha um plano pago ou adicione suas próprias chaves de fornecedor; as taxas do fornecedor são separadas.

**O Orkas é um modelo de linguagem de grande porte (LLM) que roda localmente?**
Não. O Orkas roda no seu computador e chama o modelo que você escolher: o modelo integrado do Orkas, um modelo conectado com a sua chave de API ou um modelo acessível por um endpoint local. O Orkas coordena agentes e ferramentas, mas não é um modelo.

**Os Orkas podem responder a perguntas dos meus documentos com citações?**
Sim. Adicione PDFs e documentos à sua Biblioteca local; Orkas pode pesquisar e responder com citações para as passagens de origem, para que você possa abrir o original e verificar.

**Posso usar modelos locais como Ollama ou LM Studio?**
Sim. Abra **Configurações da conta → Modelos → Chat → Adicionar modelo → Personalizado** e selecione **Compatível com OpenAI** ou **Compatível com Anthropic**. Informe a URL base, o ID exato do modelo e a chave de API. Em seguida, escolha o modelo salvo no seletor da tarefa.

**Onde estão as minhas chaves e dados da API?**
Por padrão, os dados e as chaves ficam no seu computador. As chaves dos seus provedores são criptografadas localmente e não entram na sincronização com a nuvem. Com sua própria chave, as solicitações vão do seu computador diretamente ao provedor. O modelo integrado usa um serviço gerenciado pela Orkas. Se você usar a sincronização opcional com a nuvem ou os projetos compartilhados da versão instalável, os dados selecionados serão armazenados nos servidores da Orkas. [Segurança e tratamento de dados →](https://orkas.ai/security/?source=gh-orkas)

**As Orkas funcionam offline?**
A versão executada a partir do código-fonte pode funcionar totalmente offline com um endpoint local do modelo. A versão instalável exige login, e as chamadas aos modelos na nuvem precisam de conexão com a internet.

**Continua a funcionar quando o meu computador está desligado?**
Não. O Auto-advance e as automações agendadas dependem de o computador estar ativo e de o Orkas estar em execução. A partir da versão 1.9, quando o computador sai do modo de suspensão ou o Orkas é iniciado, cada automação recupera somente a execução perdida mais recente das últimas 12 horas.

**Posso criar e publicar aplicativos?**
Sim. Os aplicativos locais que funcionam dentro da Orkas são gratuitos. Publicar um aplicativo web para um link público precisa de um plano pago (Lite 5, Pro 8, Max 15 apps), e os aplicativos web publicados não incluem todas as capacidades disponíveis dentro da Orkas.

**Preciso de uma conta Orkas?**
O aplicativo de desktop embalado pede que você inicie a sessão quando o lançar pela primeira vez. A fonte construída neste repositório não tem uma camada de conta em tudo — ele inicia diretamente no aplicativo.

**Os Orkas podem conduzir o Claude Code e outros agentes da CLI?**
Sim. Orkas pode dirigir cinco agentes externos de CLI como subprocessos locais ∙ os agentes de codificação Claude Code, Codex e OpenCode, mais os agentes pessoais OpenClaw e Hermes-Agent ∙ e em projetos de código aberto como HyperFrames, todos dirigidos a partir do mesmo chat.

**Como é que Orkas difere do Claude Code / Codex / CrewAI / LangChain?**
Claude Code e Codex são agentes de programação. O Orkas pode executar os dois na mesma equipe, sem que você precise escolher entre eles. CrewAI e LangChain são frameworks centrados em código. O Orkas é um aplicativo de desktop de código aberto em que o Commander coordena agentes especializados e seus agentes de linha de comando. Você pode escolher entre diferentes provedores de modelos. Por padrão, os dados e as chaves são armazenados localmente. [Veja a comparação completa](https://orkas.ai/compare/?source=gh-orkas)

**Que plataformas as Orkas suportam?**
Há instaladores para macOS 12+ (Apple Silicon e Intel) e Windows 10+. No Linux x64/arm64 com glibc 2.34 ou superior, o Orkas roda pelo código-fonte e ainda não tem instalador. Na primeira inicialização, o Orkas prepara uma versão fixa do ambiente de execução do whisper.cpp para transcrever voz no computador. Não há suporte para Alpine nem para outras distribuições baseadas em musl. Para iniciar pelo código-fonte, é necessário ter Node 22.12 ou superior. Python 3 e as ferramentas de compilação em C/C++ só são necessários quando um pacote nativo do npm não tem um binário pré-compilado compatível e precisa ser recompilado localmente.

**As Orkas são de código aberto e livre?**
Sim — o aplicativo é licenciado pelo MIT e gratuito para uso. O versão instalável inclui 500 créditos para o modelo Orkas incorporado; planos pagos a partir de US $ 11,99 / mês adicionam créditos mensais, sincronização em nuvem, mais projetos compartilhados e publicação de aplicativos. Com suas próprias chaves, o uso do modelo é cobrado pelo seu provedor; Orkas não adiciona uma marcação.[Preços →](https://orkas.ai/pricing/?source=gh-orkas)
