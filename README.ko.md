## 계속 진행하세요

하나의 임무는 좋은 시작입니다. Orkas는 계속되는 일에 적합합니다.

- **프로젝트** — ✓ 프로젝트의 모든 대화가 시작되는 목표와 규칙, 메모리 및 파일, 그래서 처음부터 간략하게 설명하지 않습니다.
- **과제 및 자동 진행** — 모든 프로젝트에는 사람 및 에이전트에게 해야 할 일 목록이 있습니다. 자동 진행으로 팀은 다음 항목을 스스로 선택하고 완료된 작업을 검토에 가져옵니다.
- **예약 자동화** — 작업을 매시간, 매일, 매주 또는 매월 실행할 수 있습니다. Orkas는 내 컴퓨터에서 실행됩니다. 1.9부터는 컴퓨터가 절전 모드에서 깨어나거나 앱이 시작될 때 자동화별로 직전 12시간 동안 놓친 실행 중 가장 최근 한 번만 수행합니다.
- **연결기** — Gmail, Google 캘린더, 시트 및 드라이브, 노션, Slack, Shopify, 스트라이프 등 많은 것들이 있습니다. 기본적으로 Orkas는 어떤 것을 전송하거나 게시하거나 삭제하기 전에 묻습니다.
- **앱** — 도구에 대해 설명하고 Orkas는 데스크톱 앱 내부에서 로컬 앱으로 만들 수 있습니다. 패키지 앱에서는 유료 계획 또한 공개 링크를 가진 웹 앱으로 게시 할 수 있습니다.
- **공유 프로젝트**(설치판) — 동료나 가상 비서를 초대해 각 할 일을 사람이나 에이전트에게 배정하세요.

> [!NOTE]
> 공유 프로젝트, 클라우드 동기화, 웹 앱 게시 기능은 설치판에서만 제공되며 오픈 소스 버전에서는 아직 지원되지 않습니다. 이러한 기능을 사용하려면 **[macOS 및 Windows용 Orkas 다운로드](https://orkas.ai/download/?source=gh-orkas&entry_point=github_readme&download=1)**(무료, 크레딧 500개 제공)를 이용하세요.

## 왜 Orkas가

- **계획하고, 위임하고, 나머지는 하는 Commander** — 그것은 목표를 분해하고, 적절한 요인, 기술, 연결기 및 도구를 선택하고, 어떤 전문가가 더 적합하지 않은 상태에서 분석, 글쓰기, 연구 및 파일 작업을 직접 처리합니다.
- **로컬 우선** — 대화, 파일, 지식 베이스, 맞춤 에이전트는 기본적으로 내 컴퓨터에 저장됩니다. 설치판에서는 클라우드 동기화를 켤 수 있습니다. 내 키를 쓰면 컴퓨터가 공급자에 직접 모델을 호출하고, 기본 제공 Orkas 모델은 Orkas 관리형 서비스를 사용합니다.
- **어떤 모델이든, 언제든** — Commander과 내장된 에이전트는 하나의 모델 설정: 내장된 Orkas 모델, 귀하의 개인 공급업체는 또는 지역 엔드포인트. 외부 CLI 에이전트는 자신의 모델 설정을 유지합니다.
- **더 나은 요원** — 각 에이전트는 개인 기술과 기억을 유지합니다. 배경 리뷰는 앱이 비활성일 때 새로운 활동을 조사하고 자기 평가, 재사용 가능한 방법 및 학습된 기술을 정비 할 수 있습니다.
- **오픈소스, 블랙박스 없습니다** — MIT에 라이선스 받았어 Orkas와 모든 에이전트와 실력이 무엇인지 정확히 읽어봐

## 빨리 시작

대신 패키지 설치가 필요해?[다운로드](#다운로드)위에서. 소스에서 실행하기 위해 현재 Linux에서 Orkas를 실행하는 방법은:

**요구 사항**: Node 22.12+ · macOS / Windows 10+ / glibc 2.34+ Linux x64 또는 arm64. Python 3 및 C/C++ 구축 도구 체인을 비정상적인 원천 모듈 구축 하락에 사용할 수 있도록하십시오.

```bash
git clone https://github.com/Orkas-AI/Orkas.git
cd Orkas
./run.sh           # macOS / Linux
run.cmd            # Windows
```

Linux에서 소스로 실행하려면 glibc 2.34+가 필요합니다. Alpine 및 기타 musl 기반 배포판은 지원되지 않습니다. 처음 실행할 때 로컬 음성 전사를 위해 대상 아키텍처에 맞는 whisper.cpp 런타임과 다국어 모델을 다운로드하고 검증합니다.

`run.sh` / `run.cmd`잠금된 npm 의존성 트리를 설치하고, 꽂힌 Python, uv, Node, 임베디션 모델 (~95 MB), OfficeCLI, FFmpeg, whisper.cpp 및 다국어 음성 모델 리소스를 첫 출시 시 준비합니다. Linux 시작은 다음 앱을 열기 전에 Electron의 ABI에 있는 플랫폼 네이티브 모듈과 Whisper 실행 시간을 확인합니다. OCR와 스킬 특화된 파이썬 패키지는 이러한 기능이 처음 사용되면 고립된 지역 환경에 설치됩니다. 첫 번째 출시는 작업 공간을 생성합니다`~/.orkas/`(macOS / Linux) 또는`<smallest non-system drive>:\.orkas\`(윈도우) 그럼 열어요**설정 → AI 제공자** API key 또는 OAuth를 추가하기 위해서

## 어떻게 작동하는지

### 작업 라우팅

Commander은 직접 일반 작업을 처리하고 전문적인 작업을 세 가지 도구로 위임합니다.

- **`dispatch_to`**는 이름으로 지정한 에이전트를 호출하며, 커맨더는 결과를 받아 작업을 계속합니다. 결과가 나올 때까지 기다리거나 비동기로 실행해 완료 알림을 받을 수 있습니다.
- **`hand_off_to`** — 남은 작업을 명명된 에ai전트에 전송하고 현재의 Commander 회전을 끝낸다. 에이전트는 자신의 답변을 전달한다. 선택적 연속은 지휘관이 더 넓은 작업을 다시 시작할 수 있게 한다.
- **`run_worker`** — 익명적이고 고립된 하위 작업을 실행하고 개인 결과를 반환합니다. 대화 역사 또는 이름 지어진 에이전트의 기술을 수신하지 않습니다.

이름 붙여진 에이전트 작업과 익명의 노동자들은 별도의 동시 제어 기능을 가지고 있습니다.[파견의 실행](./src/main/features/group_chat/bus.ts)그리고[실행 잠금](./src/main/util/locks.ts).

### 컨텍스트 관리

실행 시간 예산의 맥락은 선택된 모델의 사용 가능한 입력 용량, 명령어, 도구 및 지속적인 실행 시간 상태를 계산하는 것과 비교합니다. 완료 대화는 제한된 최근 역사 창을 사용합니다. 긴 활성 작업은 ai전 프로세스 메시지를 응축하는 점들을 사용하여 최근의 작업을 유지합니다. 파일 읽기, 파일 변경 및 명령 실행 또한 컨텍스트 컴팩션을 생존할 수있는 구조화된 기록을 가지고 있습니다.

보시다시피[컨텍스트 예산](./src/core-agent/src/agent/context-budget.ts), [세션 역사와 체크포인트](./src/core-agent/src/agent/session.ts)그리고[작업 공간 기록](./src/core-agent/src/agent/workspace-state.ts).

### 기억과 도서관

내구성 메모는 사용자 선호도, 프로젝트 사실 및 각 에이전트의 재사용 가능한 지식을 별도의 범위에서 보관합니다. 이 메모는 도서관 문서 지표와 저장된 대화 역사와는 다릅니다.

라이브러리는 문서에서 문단을 추출하고 로컬 SQLite 벡터 인덱스를 만듭니다. 임베딩 모델은 내 컴퓨터에서 실행됩니다. 에이전트는 `library`를 사용해 전역 또는 현재 프로젝트 라이브러리의 파일 목록을 보고, 관련 문단을 검색하며, 원문을 읽을 수 있습니다. 이전 대화는 `chat_history`로 따로 검색합니다.

보시다시피[범위의 메모리](./src/main/features/memory.ts), [문서 추출](./src/main/util/file_to_chunks.ts), [도서관 도구](./src/main/model/core-agent/kb-tools.ts)그리고[대화 검색](./src/main/model/core-agent/chat-history-tools.ts).

### 집행 제한 및 회수

세션 잠금과 동시 실행 한도로 병렬 작업을 제어합니다. 도구 호출 횟수 제한, 진행 체크포인트, 반복 호출 검사, 단계별 유휴 상태 모니터링으로 작업 정체나 반복을 억제합니다. 이름이 지정된 에이전트의 작업은 개별적으로 추적하고 취소할 수 있습니다. 접수되었거나 대기열에 들어간 작업은 완료로 처리하지 않습니다.

보시다시피[배우 예산](./src/main/features/group_chat/actor-budgets.ts),[에이전트 런타임](./src/core-agent/src/agent/runner.ts)그리고[데스크톱 모델 어댑터](./src/main/model/core-agent/client.ts).

### 활동 으로 부터 배우는 것

백그라운드 검토는 앱이 유휴 상태일 때 에이전트의 새로운 활동을 확인하며, 재실행 간격과 실행 제한을 지킵니다. 자체 평가(`COMPETENCE.md`), 재사용할 수 있는 방법(`LEARNING_STRATEGIES.md`), 새로 익힌 스킬을 업데이트하거나 저장할 내용이 없다고 판단할 수 있습니다. 완료된 작업 수가 아니라 새로운 활동을 기준으로 실행됩니다.

이[반사 스케줄러](./src/main/features/reflection-orchestrator.ts)그리고[검토 시급](./src/core-agent/src/evolution/metacognition.ts).

## FAQ

**Orkas란 무엇인가?**
Orkas는 로컬 우선 방식으로 동작하는 오픈 소스(MIT) 멀티 에이전트 데스크톱 앱입니다. 커맨더는 목표를 할 일로 나누고 기본 제공 전문 에이전트 16개와 Claude Code, Codex, OpenCode, OpenClaw, Hermes-Agent를 조율해 완성된 파일을 전달합니다.

**API key가 필요해?**
아니요. 설치판에는 기본 제공 Orkas 모델을 쓸 수 있는 크레딧 500개가 포함됩니다. 크레딧을 모두 사용한 뒤에는 크레딧을 구매하거나 유료 플랜을 선택하거나 자체 공급자 키를 추가할 수 있습니다. 자체 공급자 요금은 별도로 청구됩니다.

**Orkas는 로컬 대규모 언어 모델(LLM)인가요?**
아닙니다. Orkas는 컴퓨터에서 실행되며, 기본 제공 Orkas 모델, 내 API 키로 연결한 모델, 로컬 모델 엔드포인트 중에서 선택한 모델을 호출합니다. 에이전트와 도구를 조율하지만 Orkas 자체가 모델인 것은 아닙니다.

**Orkas는 문서를 인용해서 답변할 수 있을까요?**
네. 로컬 라이브러리에 PDF 파일과 문서를 추가하세요. Orkas는 검색하여 소스 페이지를 인용하여 답변할 수 있습니다. 그래서 원본을 열고 확인할 수 있습니다. 지수는 컴퓨터에 구축됩니다.

**올라마나 LM 스튜디오 같은 로컬 모델들을 사용할 수 있나요?**
네. **계정 설정 → 모델 → 채팅 → 모델 추가 → 사용자 지정**에서 **OpenAI 호환** 또는 **Anthropic 호환**을 선택하세요. 기본 URL, 정확한 모델 ID, API 키를 입력한 뒤 작업의 모델 선택 메뉴에서 저장한 모델을 고르면 됩니다.

**내 API key와 데이터가 어디에 저장되어 있습니까?**
데이터와 키는 기본적으로 내 컴퓨터에 저장됩니다. 내 공급자 키는 로컬에서 암호화되며 클라우드 동기화 대상에서 제외됩니다. 내 키를 쓰면 컴퓨터에서 공급자로 직접 모델 호출을 보내고, 기본 제공 Orkas 모델을 쓰면 Orkas 관리형 서비스를 이용합니다. 설치판에서 선택 기능인 클라우드 동기화나 공유 프로젝트를 이용하면 선택한 데이터는 Orkas 서버에 저장됩니다. [보안 및 데이터 처리 →](https://orkas.ai/security/?source=gh-orkas)

**Orkas는 오프라인에서 작동합니까?**
소스 빌드는 로컬 모델 엔드포인트에 완전히 오프라인으로 실행될 수 있습니다. 패키지 앱은 로그인해야 하며 클라우드 모델에는 네트워크 연결ai 필요합니다.

**컴퓨터가 꺼져 있으면 계속 작동합니까?**
아닙니다. Auto-advance와 예약 자동화는 컴퓨터가 깨어 있고 Orkas가 실행 중일 때만 작동합니다. 1.9부터 컴퓨터가 절전 모드에서 깨어나거나 Orkas가 시작되면, 각 자동화에서 직전 12시간 동안 놓친 실행 중 가장 최근 한 번만 수행합니다.

**앱을 만들고 출판할 수 있나요?**
예. Orkas 내에서 실행되는 로컬 앱은 무료입니다. 공개 링크에 웹 앱을 게시하려면 유료 플랜 (Lite 5, Pro 8, Max 15 앱) ai 필요합니다. 그리고 출판된 웹 앱은 Orkas 내부에서 사용할 수있는 모든 기능을 포함하지 않습니다.

**Orkas 계좌가 필요해?**
패키지 데스크톱 앱은 처음 시작했을 때 로그인하도록 요청합니다. ai 저장소에서 생성된 소스에는 전혀 계정 계층이 없습니다.

**Orkas는 Claude Code와 다른 CLI 요원을 운전할 수 있나요?**
Orkas는 5개의 외부 CLI 에이전트를 로컬 하위 프로세스로 켜고 있습니다. 코드링 에이전트 Claude Code, Codex 및 OpenCode, 개인 에이전트 OpenClaw와 Hermes-Agent 그리고 HyperFrames즈 같은 오픈소스 프로젝트에서 모두 같은 채팅에서 지시됩니다.

**Orkas는 Claude Code, Codex, CrewAI, LangChain과 어떻게 다른가요?**
Claude Code와 Codex는 코딩 에이전트로, Orkas에서 둘 다 팀원으로 실행할 수 있습니다. CrewAI와 LangChain은 코드 중심 프레임워크입니다. Orkas는 커맨더가 전문 에이전트와 CLI 에이전트를 조율하는 오픈 소스 데스크톱 앱입니다. 여러 모델 공급자 중에서 선택할 수 있으며 데이터와 키는 기본적으로 로컬에 저장됩니다. [전체 비교 보기](https://orkas.ai/compare/?source=gh-orkas)

**Orkas가 지원하는 플랫폼은 무엇일까요?**
macOS 12+(Apple Silicon 및 Intel)와 Windows 10+용 설치 프로그램이 있습니다. glibc 2.34+ Linux x64/arm64에서는 현재 소스로 실행해야 하며 설치 프로그램은 아직 없습니다. 첫 실행 시 로컬 음성 전사용 whisper.cpp 런타임을 지정된 버전으로 준비합니다. Alpine 등 musl 기반 배포판은 지원되지 않습니다. 소스 실행에는 Node 22.12+가 필요하며, Python 3과 C/C++ 빌드 도구 체인은 네이티브 npm 패키지에 호환되는 사전 빌드 바이너리가 없어 로컬에서 다시 빌드해야 할 때만 필요합니다.

**Orkas는 무료이고 오픈소스인가요?**
예 ️ 앱은 MIT 라ai선스 및 사용 무료입니다. 패키지 응용 프로그램은 내장된 Orkas 모델에 대한 500 크레딧을 포함합니다. 월 11.99 달러 / 달부터 지불 된 계획은 월별 크레딧, 클라우드 동기화, 더 많은 공유 프로젝트 및 응용 프로그램 출판을 추가합니다. 자신의 키와 함께, 모델 사용은 공급자가 청구합니다. Orkas는 표시를 추가하지 않습니다.[가격](https://orkas.ai/pricing/?source=gh-orkas)
