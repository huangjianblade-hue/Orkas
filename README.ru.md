# Orkas

**Команда агентов AI с открытым исходным кодом на вашем рабочем столе превращает ваши цели в законченную работу и поддерживает ее в движении.**

Orkas - это открытый исходный код (MIT), первое локальное многоагентское рабочее место**Commander** что вам нужно: он выполняет многие задачи самостоятельно, а для больших работ он планирует шаги и привлекает специализированных агентов вместе с кодированием и персональными агентами, которые вы уже используете**Claude Code, Codex, OpenCode, OpenClaw и Hermes-Agent** — работать над этим вместе.

Orkas помогает вести проекты, а не только отвечать на отдельные вопросы. В **проекте** хранятся цели, правила, память и файлы, чтобы в новом чате можно было продолжить работу с того же места. **Задачи** назначаются людям и агентам. Функция **Auto-advance** позволяет команде самостоятельно перейти к следующей задаче. **Автоматизация по расписанию** повторяет рутинные операции каждый час, день, неделю или месяц. Все ваши данные остаются на вашем компьютере, а готовые результаты передаются вам на проверку. Так вы можете доверить Orkas рабочие задачи, которыми нужно заниматься на постоянной основе.

### Создать видео с собственным содержанием

**VideoStudio** может взять за основу структуру повествования, визуальный стиль и темп монтажа популярного видео и создать новый ролик с вашим продуктом, текстом и материалами. Предоставьте файл с видеообразцом и свои материалы. Агент проанализирует, как ролик захватывает внимание, в каком порядке подаётся информация, как меняются кадры и к какому действию призывают зрителя. До начала производства он предложит, что сохранить и что заменить.

Этот подход подходит для объясняющих роликов с анимированным текстом, демонстраций SaaS-сервисов или приложений и рекламы на основе готовых материалов о товаре. Отдельно созданные текст, субтитры, озвучку и фрагменты можно редактировать независимо друг от друга. Чтобы изменить текст внутри кадра, сгенерированного ИИ, нужно отредактировать сам кадр.

> «Возьми reference.mp4 за образец и сделай вертикальный рекламный ролик на 30 секунд. Сохрани приём, которым он цепляет зрителя в начале, стиль шрифтов и темп, но используй мой продукт и записи экрана. Сначала покажи разбор ролика и план производства».

Предоставьте видеофайл, который агент может прочитать. Скачивание видео по ссылкам для общего доступа из соцсетей не встроено. Точное повторение движений камеры, игры актёров и каждого кадра не гарантируется. См. [процесс создания ролика по видеообразцу](./resources/builtin/marketplace/agents/79df9cc89f5f/skills/video-craft/references/reference-recreation.md).

## Продолжайте работать

Одно из задач - это хороший старт. Orkas построены для работы, которая продолжается.

- **Проекты** — цели и правила, память и файлы, с которых начинается каждый разговор в проекте, так что вы никогда не будете кратко рассказывать о начале.
- **До-до и Авто-аванс** — каждый проект имеет список задач для людей и агентов; с автопрогрессом команда сама по себе подбирает следующий пункт и возвращает законченную работу для вашего обзора.
- **Автоматизации по расписанию** — Запускайте задачи каждый час, день, неделю или месяц. Orkas работает на вашем компьютере. Начиная с версии 1.9, при выходе компьютера из спящего режима или запуске Orkas каждая автоматизация выполняет только последний запуск, пропущенный за предыдущие 12 часов.
- **Сключатели** — Gmail, Google Calendar, Sheets and Drive, Notion, Slack, Shopify, Stripe и многое другое.
- **Приложения** — описывать инструмент и Orkas создает его как локальное приложение внутри настольного приложения. В упакованном приложении платные планы также могут публиковать его в качестве веб-приложения с общественной ссылкой.
- **Совместные проекты** — *(упаковано приложение)*пригласить товарища по команде или ВА, и дать каждое задание человеку или агенту.

## Почему орки

- **Commander, который планирует, делегирует и делает все остальное.** — он разлагает цели, выбирает подходящих агентов, навыков, соединителей и инструментов, и сам решает анализ, написание, исследования и работу с файлами, когда ни один специалист не подходит лучше.
- **Приоритет локального хранения** — Диалоги, файлы, базы знаний и пользовательские агенты по умолчанию хранятся на вашем компьютере. В устанавливаемой версии можно включить облачную синхронизацию. С собственным ключом запросы к модели отправляются напрямую с вашего компьютера провайдеру; встроенная модель Orkas использует сервис под управлением Orkas.
- **Любая модель, перемены в любое время** — Commander и встроенные агенты разделяют одну модель: встроенную модель Orkas, собственного поставщика или локальный конечный пункт.
- **Агенты , которые улучшаются** — каждый агент сохраняет свои навыки и память.
- **Открытый код, нет черной коробки** — Прочитайте, что делают Orkas и все агенты и навыки.

## Быстрый старт

Хочешь вместо этого упакованную установку?[Скачать](#скачать)Для запуска из источника      в настоящее время способ запуска Orkas на Linux:

**Требования**: Node 22.12+ · macOS / Windows 10+ / glibc 2.34+ Linux x64 или arm64. Держите Python 3 и цепочку инструментов по созданию C/C++ доступны для необычного восстановления создания исходных модулей.

```bash
git clone https://github.com/Orkas-AI/Orkas.git
cd Orkas
./run.sh           # macOS / Linux
run.cmd            # Windows
```

Для запуска из исходного кода в Linux нужна glibc 2.34 или новее. Alpine и другие дистрибутивы на базе musl не поддерживаются. При первом запуске из исходного кода Orkas загружает и проверяет среду выполнения whisper.cpp для нужной архитектуры и многоязычную модель для локального распознавания речи.

`run.sh` / `run.cmd` загружает запертое дерево зависимости npm и готовит закрепленный Python, uv, Node, встроенный модель (~95 MB), OfficeCLI, FFmpeg, whisper.cpp и многоязычные ресурсы модели речи при первом запуске. Затем стартап Linux проверяет платформенные модули и время работы Whisper под ABI Electron перед открытием приложения. Пакеты Python для OCR и отдельных навыков устанавливаются в изолированные локальные окружения при первом использовании соответствующих функций. При первом запуске создаётся рабочая область в `~/.orkas/` (macOS / Linux) или `<smallest non-system drive>:\.orkas\` (Windows). Затем откройте **Настройки → Провайдеры AI**, чтобы настроить ключ API или OAuth.

При ошибках нативных зависимостей используйте Node.js 24 LTS (минимум 22.12.0) и выполните в этом каталоге исходного кода
`npm run native:repair`. Команда восстанавливает необязательные зависимости,
восстанавливает сборку SQLite для Electron и проверяет SQL и sqlite-vec. Кроме того,
команда подготавливает включённую в комплект среду выполнения Node и проверяет sharp в отдельном процессе, прежде чем сообщить об успехе.
Использование`npm run native:check`для проверки без установки.
Смотрите[скрипт проверки зависимости на родине](./scripts/verify-native-dependencies.cjs)для проведенных проверок.

## Как это работает

### Направление задач

Commander сам занимается общей работой и делегирует специализированную работу через три инструмента:

- **`dispatch_to`** — Он может ждать результата или запускать его асинхронно и сообщать командующему, когда задача закончится.
- **`hand_off_to`** передаёт оставшуюся работу агенту, указанному по имени, и завершает текущий ход Commander. Агент отвечает напрямую. При необходимости можно задать следующий шаг, чтобы Commander позднее вернулся к более широкой задаче.
- **`run_worker`** — Он выполняет анонимную и изолированную задачу, и возвращает частный результат.

Назначенные задачи агента и анонимные работники имеют отдельные контрольные системы одновременного управления.[реализация отправки](./src/main/features/group_chat/bus.ts)и[замок исполнения](./src/main/util/locks.ts).

### Управление контекстом

Контекст бюджетного времени запуска в сравнении с использоваемой возможностью ввода выбранной модели, учетом запросов, инструментов и постоянного состояния времени запуска. Завершенный диалог использует ограниченное окно недавней истории; длинные активные задачи используют контрольные точки для конденсации более ранних сообщений процесса при сохранении недавней работы. Читание файлов, изменения файлов и выполнение команд также имеют структурированные записи, которые могут пережить сжатие контекста.

Посмотрите[контекстные бюджеты](./src/core-agent/src/agent/context-budget.ts), [история сеанса и пункты пропуска](./src/core-agent/src/agent/session.ts)и[записи рабочего пространства](./src/core-agent/src/agent/workspace-state.ts).

### Память и библиотека

Прочные записки хранят предпочтения пользователей, факты проекта и многократные знания каждого агента в отдельных объемах.

Библиотека извлекает абзацы из документов и создаёт локальный векторный индекс SQLite. Модель эмбеддингов работает на вашем компьютере. С помощью `library` агенты могут перечислять файлы, искать подходящие фрагменты и читать исходные материалы в общей библиотеке или библиотеке текущего проекта. Поиск по старым диалогам выполняется отдельно через `chat_history`.

Посмотрите[охватная память](./src/main/features/memory.ts), [извлечение документов](./src/main/util/file_to_chunks.ts), [Библиотечные инструменты](./src/main/model/core-agent/kb-tools.ts)и[восстановление разговора](./src/main/model/core-agent/chat-history-tools.ts).

### Лимиты исполнения и возмещение

Замок сессии и ограничения совпадения, связанные с параллельной работой. Бюджеты инструмента, контрольные пункты прогресса, проверки повторных вызовов и фазосознательные безработные наблюдатели помогают удержать запуска, которые задерживают или повторяют работу.

Посмотрите[бюджеты актеров](./src/main/features/group_chat/actor-budgets.ts),[время работы агента](./src/core-agent/src/agent/runner.ts)и[адаптер настольной модели](./src/main/model/core-agent/client.ts).

### Учение от деятельности

Фоновый анализ проверяет новую активность агентов, когда приложение простаивает. Он выполняется с заданными интервалами и ограничениями. Он может обновить самооценку (`COMPETENCE.md`), повторно используемые методы (`LEARNING_STRATEGIES.md`) или освоенные навыки либо решить, что сохранять нечего. Анализ планируется по новой активности, а не по числу выполненных задач.

Смотрите[график отражения](./src/main/features/reflection-orchestrator.ts)и[проспект обзора](./src/core-agent/src/evolution/metacognition.ts).

## Часто задаваемые вопросы

**Что такое Orkas?**
Orkas — многоагентное настольное приложение с открытым исходным кодом (MIT), ориентированное на локальную работу. Commander разбивает цель на задачи и координирует 16 встроенных агентов-специалистов, а также Claude Code, Codex, OpenCode, OpenClaw и Hermes-Agent, чтобы подготовить готовые файлы.

**Мне нужен ключ API?**
Нет. упакованное приложение поставляется с 500 кредитами для встроенной модели Orkas. После этого, купите кредиты, выберите платный план или добавьте собственные ключи провайдера; расходы провайдера отдельны.

**Orkas — это локальная большая языковая модель (LLM)?**
Нет. Orkas работает на вашем компьютере и обращается к выбранной модели: встроенной модели Orkas, модели, подключённой с помощью вашего API-ключа, или модели на локальной конечной точке. Orkas координирует работу агентов и инструментов, но сам моделью не является.

**Orkas могут ответить на вопросы из моих документов с цитатами?**
Да. Добавьте PDF-файлы и документы в местную библиотеку; Orkas может искать их и отвечать с цитатами на исходные отрывки, чтобы вы могли открыть оригинал и проверить.

**Могу ли я использовать местные модели, такие как Оллама или LM Studio?**
Да. Откройте **Настройки учётной записи → Модели → Чат → Добавить модель → Пользовательская**. Выберите **Совместимость с OpenAI** или **Совместимость с Anthropic**, укажите базовый URL, точный идентификатор модели и ключ API. Затем выберите сохранённую модель в настройках задачи.

**Где хранятся мои API-ключи и данные?**
По умолчанию данные и ключи хранятся на вашем компьютере. Ваши ключи провайдеров шифруются локально и не синхронизируются с облаком. Если вы используете свой ключ, запросы к модели идут напрямую с компьютера к провайдеру. Встроенная модель работает через управляемый сервис Orkas. При использовании необязательной облачной синхронизации или общих проектов в устанавливаемой версии выбранные данные хранятся на серверах Orkas. [Безопасность и обработка данных →](https://orkas.ai/security/?source=gh-orkas)

**Orkas работают вне сети?**
Версия из исходного кода может работать полностью офлайн с локальной конечной точкой модели. Версия с установщиком требует входа в учётную запись, а для обращений к облачным моделям нужен интернет.

**Он работает, когда мой компьютер выключен?**
Нет. Для Auto-advance и автоматизаций по расписанию компьютер должен быть активен, а Orkas — запущен. Начиная с версии 1.9, при выходе компьютера из спящего режима или запуске Orkas каждая автоматизация выполняет только последний запуск, пропущенный за предыдущие 12 часов.

**Могу ли я создавать и публиковать приложения?**
Да. Местные приложения, работающие внутри Orkas бесплатны. Публикация веб-приложения на публичную ссылку требует платного плана (Lite 5, Pro 8, Max 15 приложения), а опубликованные веб-приложения не включают все возможности, доступные внутри Orkas.

**Мне нужен счет Orkas?**
При первом запуске установленного приложения нужно войти в учётную запись. У версии, запускаемой из исходного кода этого репозитория, нет модуля учётных записей: приложение открывается сразу.

**Orkas могут водить Клода Кода и других агентов СИЗ?**
Да. Orkas может управлять пятью внешними агентами CLI в качестве местных подпроцессов ‒ агентами кодирования Claude Code, Codex и OpenCode, плюс персональными агентами OpenClaw и Hermes-Agent ‒ и на борту проектов с открытым исходным кодом, таких как HyperFrames, все направленные из одного чата.

**Чем Orkas отличается от Claude Code / Codex / CrewAI / LangChain?**
Claude Code и Codex — агенты для программирования. Orkas может запускать обоих в одной команде, поэтому выбирать между ними не нужно. CrewAI и LangChain — фреймворки, ориентированные на написание кода. Orkas — настольное приложение с открытым исходным кодом, в котором Commander координирует работу специализированных агентов и CLI-агентов. Можно выбирать из разных поставщиков моделей. Данные и ключи по умолчанию хранятся локально. [Смотреть полное сравнение](https://orkas.ai/compare/?source=gh-orkas)

**Какие платформы поддерживают Орка?**
Установщики доступны для macOS 12+ (Apple Silicon и Intel) и Windows 10+. Для Linux x64/arm64 с glibc 2.34 или новее установщика пока нет: Orkas запускается из исходного кода. При первом запуске Orkas подготавливает фиксированную версию среды выполнения whisper.cpp для локального распознавания речи. Alpine и другие дистрибутивы на базе musl не поддерживаются. Для запуска из исходного кода нужен Node 22.12 или новее. Python 3 и инструменты сборки C/C++ нужны только для локальной пересборки нативного npm-пакета, если у него нет совместимого готового двоичного файла.

**Orkas свободный и открытый?**
Да — приложение лицензировано MIT и бесплатное для использования. Обусловленное приложение включает в себя 500 кредитами для встроенной модели Orkas; платные планы от $ 11,99 / месяц добавляют ежемесячные кредиты, облачная синхронизация, больше совместных проектов и публикация приложений. С вашими собственными ключами использование модели зачисляется вашим провайдером; Orkas не добавляет маркировку.[Цены →](https://orkas.ai/pricing/?source=gh-orkas)
